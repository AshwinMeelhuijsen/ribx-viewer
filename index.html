RIBX Kaartviewer Web

Online viewer voor reiniging/uitvoering. Werkt direct via browser op telefoon, tablet en computer.
De viewer draait online, maar het RIBX-bestand wordt lokaal in de browser gelezen. Er wordt niets naar een server geüpload. Op iPhone/iPad: open eerst deze viewer en kies daarna via deze knop het RIBX-bestand uit Bestanden/iCloud Drive.
